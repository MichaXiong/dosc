# P1.5 基础场景搭建

> 阶段 P1 · 相机、灯光、天空、灰盒几何与材质，以及场景资产本身如何保存。

## 概念与定位

一个「能看」的场景最少包含：**相机（谁在看）**、**光照（为何能看见）**、**物体（看什么）**。天空盒与环境光决定氛围；材质决定物体表面如何响应光照。灰盒（Primitive）用于先定空间与玩法，再换美术。

---

## 相机（基础）

Game 视图 = Tag 为 `MainCamera` 的相机画面。

| 属性 | 作用 |
|------|------|
| Transform | 机位与朝向 |
| Field of View | 透视广角程度 |
| Clipping Near/Far | 近/远裁剪 |
| Clear Flags | Skybox / Solid Color… |
| Projection | Perspective / Orthographic |

**Align With View**：把选中相机对齐到当前 Scene 视角，快速定机位。场景里建议只保留一个 **Audio Listener**（默认在主相机）。玩法跟拍、Cinemachine 见 P3.5；此处先固定机位即可。

---

## 灯光与环境（基础）

**Directional Light**：平行光，模拟太阳；调 Rotation 改阴影方向，Intensity/Color 改亮度冷暖。灰盒阶段一盏平行光 + 合理环境光通常足够。

其它类型：Point（点光）、Spot（聚光）、Area（面光，多与烘焙相关）。实时灯数量影响性能。

**Lighting** 窗口中的 Environment：环境光可来自 Skybox / Gradient / Color。换天空盒常会改变整体氛围与反射感觉（视管线而定）。

---

## 天空盒（基础）

- Lighting → Environment → **Skybox Material** 指定天空材质  
- 或相机 Clear Flags = **Solid Color** 做纯色背景（菜单/调试常用）  

天空影响背景与环境感；物体是否可读仍取决于直射光、环境光、材质与曝光。

---

## Primitive 与材质（基础）

| Primitive | 常见用途 |
|-----------|----------|
| Cube | 墙、箱、台阶 |
| Plane / Quad | 地面、广告牌 |
| Sphere / Capsule | 占位角色、拾取物 |

Mesh Renderer 通过 **Material** 决定着色。创建 Material → 选匹配管线的 Shader（URP Lit/Unlit 或 Built-in Standard）→ 赋给物体。Shader 与管线不匹配会显示洋红色。

常用进阶：

- 多物体共用同一 Material，改色会一起变——要独立颜色就建新材质  
- Emission 可做自发光路标；Metallic/Smoothness 控制质感  
- 材质放 `Art/Materials/`，Prefab 引用，保持场景干净  

---

## 场景保存与多场景（基础 + 进阶概念）

- 场景是 `.unity` 资产，应连同 `.meta` 进版本库；`Ctrl+S` 保存  
- Play 模式中的修改默认不写回场景，停 Play 后再改并保存  
- 多场景拆分（Boot / Menu / Level）是工程化做法；运行时加载见 P5.1  
- **Build Settings** 里的列表决定打包包含哪些场景、默认启动哪一个（索引 0）  

---

## 常见误区

- Game 全黑：无灯、环境光过暗、物体在相机背后、Layer 被剔除  
- Plane 看不见：法线背对相机或相机在面下  
- 粉红材质：Shader 管线不对  
- 未把场景加入 Build Settings，打包后找不到关卡

## 面试题

### Q1. Game 视图和 Scene 视图分别看的是什么？主相机如何快速对齐 Scene 视角？
**参考答案：**  
Scene 是编辑视角；Game 是运行时玩家画面，由 Tag 为 `MainCamera` 的相机渲染。选中相机后用 **Align With View** 可把相机对齐到当前 Scene 视角，便于定机位。

### Q2. Directional Light 和 Point/Spot 光有什么本质区别？
**参考答案：**  
Directional 是平行光，只有方向、无位置衰减，适合太阳/月光，照亮全场景。Point 从一点向四周衰减；Spot 是锥形聚光。灰盒阶段常用一盏 Directional + 环境光；实时灯过多会影响性能。

### Q3. 物体变洋红（品红）通常是什么原因？
**参考答案：**  
材质的 Shader 与当前渲染管线不匹配（例如 Built-in 材质进了 URP 项目），或 Shader/材质引用丢失。处理：换成对应管线的 Shader（如 URP Lit），或修复 Missing 引用。

### Q4. 为什么说场景要加入 Build Settings？多场景拆分一般怎么理解？
**参考答案：**  
打包/独立运行只包含 Build Settings 列表中的场景，索引 0 通常为启动场景。工程化时常拆 Boot/菜单/关卡等多场景，运行时再用 `SceneManager` 加载；编辑期忘记 Add Open Scenes 会导致真机找不到关卡。
