# P2.3 常用类型、集合与协程

> 阶段 P2 · 向量/四元数与集合是玩法数据基础；协程是主线程上的分帧流程工具。

## Vector 与 Quaternion（基础）

| 类型 | 用途 |
|------|------|
| `Vector2` | UI、2D、输入轴 |
| `Vector3` | 3D 位置、方向、缩放 |
| `Quaternion` | 旋转（避免长期欧拉累加万向节问题） |

```csharp
Vector3 dir = (target.position - transform.position).normalized;
float dist = Vector3.Distance(a, b);
transform.position += dir * speed * Time.deltaTime;

transform.rotation = Quaternion.LookRotation(dir, Vector3.up);
transform.rotation = Quaternion.Slerp(transform.rotation, targetRot, t);
```

`normalized` 取方向；按秒移动乘 `Time.deltaTime`。`Lerp`/`Slerp` 的 t 常用 `Clamp01` 或指数平滑（见相机章节）。

## 数组、List、Dictionary（基础）

| 结构 | 场景 |
|------|------|
| `T[]` | 长度固定、热路径 |
| `List<T>` | 数量常变 |
| `Dictionary<TKey,TValue>` | ID→配置/实例查找 |

常用进阶：复用成员 `List` 作缓冲，避免在 `Update` 里频繁 `new` 造成 GC；正式项目配合对象池（P5.2）。查找用 `TryGetValue`，避免 KeyNotFound。

## 协程（基础）

协程在**主线程**把逻辑拆到多帧：`IEnumerator` + `yield return` 暂停，之后从断点继续。不是新线程，可安全使用 Unity API。

```csharp
using System.Collections;
using UnityEngine;

public class Demo : MonoBehaviour
{
    void Start() => StartCoroutine(Intro());

    IEnumerator Intro()
    {
        Debug.Log("A");
        yield return new WaitForSeconds(1f); // 受 timeScale 影响
        Debug.Log("B");
        yield return null;                   // 下一帧
        Debug.Log("C");
    }
}
```

### 启停

```csharp
Coroutine _h;
_h = StartCoroutine(Job());
StopCoroutine(_h);
StopAllCoroutines(); // 本组件上全部
```

组件禁用/销毁时未完成协程会停止。用字符串 `StartCoroutine("Name")` 易碎，不推荐。

### 常用 yield

| 指令 | 含义 |
|------|------|
| `null` | 下一帧 |
| `WaitForSeconds` | 游戏时间秒（受 timeScale） |
| `WaitForSecondsRealtime` | 真实时间（暂停仍走） |
| `WaitForFixedUpdate` / `WaitForEndOfFrame` | 物理后 / 帧末 |
| `WaitUntil` / `WaitWhile` | 条件等待 |
| `yield return StartCoroutine(...)` | 等待子协程结束 |
| `yield break` | 结束本协程 |

固定间隔可缓存 `WaitForSeconds` 实例，减少 GC。

## 协程常用进阶

**适合**：延迟、流程步骤（前摇/后摇）、淡入淡出插值、等待资源/目标就绪。  
**不适合**：替代整个游戏主循环；重 CPU 计算（会卡主线程）；复杂长期状态（用状态机更清晰，P5.4）。

```csharp
IEnumerator FadeMove(Vector3 to, float duration)
{
    Vector3 from = transform.position;
    float t = 0f;
    while (t < 1f)
    {
        t += Time.deltaTime / duration;
        transform.position = Vector3.Lerp(from, to, Mathf.Clamp01(t));
        yield return null;
    }
}
```

并行：多次 `StartCoroutine`。串行：`yield return StartCoroutine(A())`。开新循环前先停旧句柄，避免叠加。

物体销毁后若还要跑流程，把协程开在常驻对象（如 GameManager）上。

---

## 常见误区

- `while(true)` 忘记 `yield` → 卡死主线程  
- 把协程当成多线程  
- `timeScale=0` 时仍用 `WaitForSeconds` 等不到  
- 未激活物体上启动协程失败

## 面试题

### Q1. Unity 协程是多线程吗？和 `Update` 比适合做什么？
**参考答案：**  
协程跑在**主线程**，只是把函数拆到多帧执行，不是多线程，因此可安全用 Unity API，但不能靠它做重 CPU 并行。适合延迟、分步骤流程、等待条件、插值动画；每帧持续输入/移动仍更适合 `Update`。复杂长期状态更宜状态机。

### Q2. `WaitForSeconds` 和 `WaitForSecondsRealtime` 有何区别？
**参考答案：**  
前者走游戏时间，受 `Time.timeScale` 影响（暂停为 0 时等不到）；后者走真实时间，暂停菜单倒计时常用 Realtime。还有 `yield return null` 等下一帧，`WaitUntil`/`WaitWhile` 等条件。

### Q3. 如何停止协程？物体销毁后协程还会跑吗？
**参考答案：**  
保存 `StartCoroutine` 返回的 `Coroutine` 句柄，用 `StopCoroutine`；或 `StopAllCoroutines` 停本组件全部。组件禁用/物体销毁后未完成协程会停止。若流程需在销毁后继续，应把协程开在常驻对象上。

### Q4. 协程里 `while(true)` 忘记 `yield` 会发生什么？
**参考答案：**  
同一帧内死循环占满主线程，编辑器/游戏卡死。循环体必须有 `yield return`。也不要用字符串方式启动协程（易碎、难维护）。

### Q5. `Vector3.normalized` 和直接用方向向量移动时为什么常乘 `Time.deltaTime`？
**参考答案：**  
`normalized` 得到单位方向；再乘速度得到「每秒位移」，乘 `deltaTime` 转为「本帧位移」，从而帧率变化时速度感稳定。旋转同理常结合 `deltaTime` 做角速度。
