# P3.4 角色移动实现

> 阶段 P3 · 三种移动路径的选型，以及 CharacterController 下的重力、跳跃、接地与斜坡。

## 概念与定位

角色「怎么动」决定手感与物理互动方式：

| 方式 | 要点 | 适用 |
|------|------|------|
| Transform | 直接改位置 | 子弹、无碰撞原型 |
| Rigidbody | `velocity` / 力，写在 FixedUpdate | 载具、布娃娃、强物理互动 |
| CharacterController | `Move` + 自管重力 | 多数人形行走（推荐入门主路径） |

要被爆炸弹飞、刚体堆叠 → Rigidbody。要上楼梯、控斜坡的「人」→ CC。

---

## Transform / Rigidbody（基础对照）

Transform 移动简单但易穿模。Rigidbody 应保留纵向速度、只改水平，并 Freeze 不必要的旋转轴，避免胶囊躺倒。

```csharp
void FixedUpdate()
{
    Vector3 vel = dir * _speed;
    vel.y = _rb.velocity.y;
    _rb.velocity = vel;
}
```

---

## CharacterController（基础）

配置 Height / Radius / Center 贴合体型；**Step Offset** 迈台阶；**Slope Limit** 可走坡度；Skin Width 过小易卡缝、过大像悬浮。

```csharp
void Update()
{
    Vector3 horizontal = moveDir * _speed;

    if (_cc.isGrounded && _velocity.y < 0f)
        _velocity.y = -2f; // 压一小段，贴地更稳

    if (_cc.isGrounded && Input.GetButtonDown("Jump"))
        _velocity.y = Mathf.Sqrt(_jumpHeight * -2f * _gravity);

    _velocity.y += _gravity * Time.deltaTime;
    _cc.Move((horizontal + Vector3.up * _velocity.y) * Time.deltaTime);
}
```

要点：用 **`Move`**，不要只改 `transform.position`；`isGrounded` 在 **Move 之后** 更新更可信；重力常取游戏化数值（如 -15～-30）。

## 常用进阶

### 落地与跳跃手感

- **Coyote Time**：离开地面后极短时间仍允许起跳  
- **Jump Buffer**：提前按跳，落地瞬间消耗缓冲起跳  
- 辅助接地：`SphereCast` 向下补判，与 `isGrounded` 组合，减少边缘闪烁  
- 落地事件：上一帧未接地 && 本帧接地  

### 相对相机移动

```csharp
Vector3 f = cam.forward; f.y = 0f; f.Normalize();
Vector3 r = cam.right;   r.y = 0f; r.Normalize();
Vector3 moveDir = (f * v + r * h).normalized;
```

### 斜坡

CC 的 Slope Limit 覆盖多数需求。进阶可将水平速度投影到地面法线平面（`Vector3.ProjectOnPlane`），减轻斜坡弹跳。Rigidbody 在斜坡易下滑，需摩擦或速度投影。

### 与动画

把 Speed、IsGrounded、Jump 传到 Animator（P4.3）；有 Root Motion 时明确「位移由动画还是脚本驱动」。

## 常见误区

- CC 与非 Kinematic Rigidbody 同时抢同一物体  
- 在 FixedUpdate 用错时间步长；或跟拍放 Update 导致抖动（相机应 LateUpdate，P3.5）  
- Slope Limit / 胶囊脚底与模型不对齐导致悬空或陷地

## 面试题

### Q1. Transform 移动、Rigidbody 移动、CharacterController 如何选型？
**参考答案：**  
Transform：简单但易穿模，适合子弹/原型。Rigidbody：走物理引擎，适合载具、强互动、布娃娃，逻辑多在 `FixedUpdate`。CharacterController：专为角色设计，台阶/斜坡友好，用 `Move` 自管重力，不自带刚体推力。多数人形行走入门优先 CC。

### Q2. 使用 CharacterController 时为什么要自己累加重力？`isGrounded` 有什么注意点？
**参考答案：**  
CC 不是 Rigidbody，不会自动受 `Physics.gravity` 那样稳定地「掉下去」，需自行维护 `velocity.y` 并在 `Move` 里带上。`isGrounded` 在调用 `Move` 之后更可信；接地时可把向下速度压成小负值帮助贴地。边缘情况可用向下 SphereCast 辅助。

### Q3. 什么是 Coyote Time？解决什么手感问题？
**参考答案：**  
离开地面后极短时间（如 0.1s）内仍允许起跳。解决「从平台边走下时以为还在地上却跳不起来」的手感问题。还可配合 Jump Buffer（提前按跳，落地瞬间起跳）。

### Q4. 相对相机移动时为什么要把相机 forward 的 Y 抹平？
**参考答案：**  
相机常有俯仰角，直接用 `cam.forward` 会导致角色走到天上/地下。把 forward/right 的 Y 置 0 再归一化，得到水平方向，角色只在地面平面移动，同时朝向与镜头一致。
