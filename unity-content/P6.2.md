# P6.2 材质、Shader 与粒子特效

> 阶段 P6 · 粒子（Shuriken）为主；材质/Shader Graph/后处理补充到「能选对、能调通」。

## 概念与定位

特效常见两层：**材质如何着色**（Shader/Material），以及 **大量元素如何生成与运动**（Particle System / VFX Graph）。入门玩法特效优先 **Particle System（CPU）**；超大规模 GPU 模拟再考虑 VFX Graph。

资源建议：`Art/VFX/Prefabs`、`Materials`、`Textures` 分离，特效做成 Prefab 便于复用与池化。

---

## Particle System 基础

创建：Effects → Particle System。主模块（Main）关键项：

| 参数 | 含义 |
|------|------|
| Duration / Looping | 时长与是否循环 |
| Start Lifetime / Speed / Size / Color | 初值；常用 Random Between Two |
| Gravity Modifier | 重力影响 |
| Simulation Space | Local 跟物体；World 适合拖尾/枪口 |
| Max Particles | 上限，防失控 |
| Play On Awake | 是否启用即播 |

**Emission**：Rate over Time 持续喷；**Bursts** 一次性爆发（受击火花常用 Rate=0 + Burst）。  
**Shape**：Cone / Sphere / Box / Circle 等决定出生区域。  
**Color/Size over Lifetime**：淡出与缩放曲线——Alpha 收到 0 比突然消失自然。  
**Renderer**：Billboard、材质（URP 用 Particles Unlit 等）、Additive 适合火光。

预览用 Inspector 上方 Simulate，不必每次进 Play。

```csharp
[SerializeField] ParticleSystem _ps;

public void PlayHit()
{
    _ps.Stop(true, ParticleSystemStopBehavior.StopEmittingAndClear);
    _ps.Play(true); // true = 含子系统
}
```

## 粒子常用进阶

### 多层与 Sub Emitters

火 = 焰 + 火星 + 烟，多个 Particle System 父子排列，根上 `Play(true)`。Sub Emitters 可在粒子死亡/碰撞时再喷，参数复杂，先稳定单层。

### 飞向目标 / 飞向 UI

- Force Field 吸引：快但不精确  
- `GetParticles` / `SetParticles` 改速度朝向目标：可控，注意 Simulation Space=World、数量别太大  
- **爆开用粒子，飞行用 UI/物体插值**：飞向 Screen Space UI 的主流做法（世界坐标 → 屏幕点 → Canvas 本地坐标），精确且方便回调  

### 性能

控 Max Particles 与 Burst；透明 Overdraw；看不见则 Stop；频繁生成用对象池，勿每帧 `new` 材质。

### Particle vs VFX Graph

| | Particle System | VFX Graph |
|--|-----------------|-----------|
| 上手 | 快 | 节点图成本 |
| 规模 | 中小 | 大数量 GPU |
| 平台 | 成熟全平台 | 依赖管线/后端 |

---

## 材质与 Shader Graph（基础）

- 材质 = Shader + 参数；管线不对 → 洋红  
- Shader Graph：节点做溶解、边缘光等；粒子缺效果时再上，默认可先用自带 Particles Shader  
- 运行时改颜色避免改共享材质：用 MaterialPropertyBlock 或独立实例  

## 后处理（基础）

URP 常用 Volume：Bloom、Vignette、Color Adjustments。Bloom 会加强 Additive 粒子，过强易糊屏——调特效时开着最终后处理预览。

---

## 常见误区

- 粉红粒子：材质/Shader 管线错误  
- Play 一次后不再播放：需 Stop/Clear 再 Play，或 Looping 已结束  
- Simulation Space 选错导致拖尾错位  
- Destroy 过早裁掉还在飞的粒子

## 面试题

### Q1. Particle System 的 Rate over Time 和 Burst 有什么区别？受击火花一般怎么配？
**参考答案：**  
Rate over Time 是持续每秒发射，适合火、雨、烟。Burst 是在某时刻打出一包粒子，适合受击/落地尘土。受击火花常用：Looping 关、Rate=0、加 Burst，再配短 Lifetime 与 Color/Size over Lifetime 淡出。

### Q2. Simulation Space 选 Local 还是 World？举例说明。
**参考答案：**  
Local：粒子相对发射器本地空间，适合绑在角色身上的光环。World：粒子位置留在世界中，发射器移动时拖尾/枪口火焰更自然。选错会出现「残影跟着拧」或「拖尾黏在身上」。

### Q3. 粒子播放一次后再次 `Play` 没效果，可能原因是什么？
**参考答案：**  
非循环系统已播完仍处于 stopped；需要先 `Stop(..., StopEmittingAndClear)` 再 `Play`。或未包含子系统（`Play(true)`）。也要检查 Play On Awake、物体是否激活、材质是否丢失导致「看似没播」。

### Q4. Particle System 和 VFX Graph 如何选型？飞向 Screen Space UI 为何常不直接用粒子飞完？
**参考答案：**  
中小玩法特效、快速迭代用 Particle System；超大规模 GPU 模拟、复杂节点特效考虑 VFX Graph（看平台支持）。飞向 UI 需要精确屏幕坐标与到达回调，主流是世界爆开用粒子，飞行用 UI 元素做坐标转换与插值，比纯粒子追 UI 更稳。

### Q5. 运行时改粒子/材质颜色时，为什么慎改共享 Material？
**参考答案：**  
改共享材质实例会影响所有使用该材质的对象。应用 `MaterialPropertyBlock` 或独立材质实例做单例特效变色，避免「改一个、全场景跟着变」。
